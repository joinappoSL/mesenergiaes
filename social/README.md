# Contenido social de Appo

Vídeos verticales 1080x1920 con la marca Appo, generados sin créditos (Chromium + ffmpeg).

- `episodes.json`: un guion por episodio (hook, puntos, CTA).
- `render.py`: `python3 render.py` renderiza todos; `python3 render.py ep01_skills_oficiales` solo uno.
- `out/`: MP4 listos y un póster JPG por episodio.
- `assets/`: logos de la guía de marca, con el fondo blanco limpiado.

Requiere `pip install playwright` y el Chromium preinstalado del entorno.
